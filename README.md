# Image

## GGO Kirito theme for Vencord

Kirito and Deathgun background with red accents. Original theme by **VaporousCreeper**; uploaded custom background preserved.

### Install with a link

Open Discord **User Settings → Vencord → Themes → Online Themes**, paste this direct CSS link, then click outside the text box to save:

```text
https://raw.githubusercontent.com/WeepingAngeIs/Image/main/GGO_Kirito_SIN.theme.css
```

Use a dark Discord appearance. Disable other full themes if their styles conflict.

### Install locally

Download [GGO_Kirito_SIN.theme.css](https://raw.githubusercontent.com/WeepingAngeIs/Image/main/GGO_Kirito_SIN.theme.css), place it in Vencord's themes folder using **Themes → Local Themes → Open Themes Folder**, and enable it. Install using one method at a time.

### Compatibility and checks

- Includes the upstream core stylesheet in the same file; no external CSS imports are needed.
- Preserves the supplied embedded PNG background (721 × 315) and custom colours.
- Corrects an invalid positioning declaration and a misspelled banner attribute in the bundled core.
- Embedded PNG decoded and verified; published CSS checked against the prepared file.
- Not visually tested in a signed-in Discord/Vencord session. Discord class-name changes may require future updates.
